# Steering essencial do workspace

Leia `AGENTS.md` e a orientação mestra quando estiver planejando arquitetura. Este projeto é local-first, orientado ao Kiro e preparado para open source. Segurança, proveniência, orçamento de execução, separação de camadas e validação são invariantes. Nunca colocar segredos no Git ou memória pública; usar dados sintéticos. Não considerar mock como funcionalidade real. Não expor CLI/ACP/SQLite/MCP diretamente na rede. Ao concluir fase, atualizar `docs/STATUS_IMPLEMENTACAO.md` com testes realmente executados.
